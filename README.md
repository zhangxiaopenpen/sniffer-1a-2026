# 带 GUI 的网络嗅探器

基于 Python、Scapy 和 PySide6 实现，面向 Windows，使用 Npcap 捕获网络数据包。提供实时抓包、协议查看、组合筛选、PCAP 文件读写、域名证据分析和双向 TCP 流重组功能。

## 实时抓包

- 枚举网络接口，显示网卡名称、IPv4 地址、默认建议和回环标记。
- 支持选择 Wi-Fi、以太网或本机回环接口，开始、停止和清空抓包；停止后可在同一接口继续累计数据。
- 默认最多保留 1000 个数据包，可在空数据状态下调整为 10–10000 个；达到包数上限或 32 MiB 原始数据预算时自动停止。
- 显示收到、保留、已显示、待处理和应用丢弃等计数，便于查看抓包与队列处理状态。

## 数据包查看

- 使用莫兰迪浅色图形界面，表格显示编号、时间、源地址、目的地址、协议、源端口、目的端口和长度。
- 选择数据包后，可查看分层协议字段及捕获时的十六进制原始数据。
- 支持查看 IPv4、IPv6、TCP、UDP、ICMP、ICMPv6 等协议的信息。
- 完成域名或 TCP 流分析后，表格追加相应列，详情区显示证据来源及关联包号。

## 组合显示筛选

- 协议条件支持全部、HTTP、TCP、UDP、IPv4、IPv6、ICMP 和 ICMPv6；HTTP 筛选检查单包起始行，不限定端口 80。
- IP 条件支持 IPv4、IPv6 地址及 CIDR 网段，端口条件支持 0–65535，均可匹配通信任一端。
- 支持域名条件，并通过“含候选”选项控制是否纳入 DNS/IP/TTL 候选证据；域名筛选需要先完成“分析域名”。
- 多项条件按 AND 组合，支持应用筛选、回车应用和重置筛选；输入非法条件时保留上一组有效筛选。
- 筛选只改变表格显示，数据包详情仍对应原始数据。

## PCAP 文件读写

- 支持打开和保存经典 PCAP 文件，读取时兼容常见大小端及微秒、纳秒时间戳格式。
- 成功导入后，可对文件中的数据包进行查看、筛选、域名分析和 TCP 流分析。
- 保存全部保留的数据包及其原始字节，保存范围不受显示筛选影响；分析结果作为界面信息展示，不写入 PCAP。
- 导入失败或取消时保留原数据；保存失败时保留内存中的数据和原有目标文件。

## 域名证据与 DNS 统计

- 解析 DNS 查询和响应，展示事务 ID、查询名称、查询类型、A/AAAA/CNAME 记录、TTL 和关联包号。
- 提取单个数据包内完整的 HTTP Host 和 TLS ClientHello SNI 字段，显示域名及其依据。
- 关联 DNS 查询与响应，并根据响应地址和 TTL 为相关数据包生成域名候选；候选与直接证据分开展示。
- 展示 DNS 查询数、DNS 响应数、成功匹配事务数、未匹配查询数和唯一直接域名数五项统计。
- 统计基于完整分析快照，显示筛选不改变统计值；唯一直接域名数对 DNS、单包 HTTP Host 和 TLS SNI 证据去重，不计入候选。
- 分析基于已捕获或导入的数据，域名证据可追溯到对应数据包。

## 双向 TCP 流重组

- 按 IPv4/IPv6 地址和端口组织双向 TCP 会话，展示流编号、通信方向、流状态及会话端点。
- 根据 TCP 序号重排载荷，处理乱序、重传、序号回绕、重叠冲突和缺口，并记录观察到的 SYN、FIN、RST。
- 展示各方向连续载荷字节数、重复或重叠字节、原始包号和跨段证据。
- 在请求方向观察到初始 SYN，且整个流没有缺口、重叠冲突或预算截断时，从连续载荷起点解析完整 HTTP/1 请求头或 TLS ClientHello，提取跨 TCP 分段的 Host 或 SNI。
- 对缺口、冲突、起点未知和预算截断等情况显示状态，避免将不完整流作为确定域名证据。
- TCP 流分析结果独立展示，不改变 DNS 统计，也不自动加入单包域名筛选；TLS SNI 来自可见握手字段，不代表 HTTPS 内容解密。

## 命令行抓包

- 提供网卡枚举、交互式选择和指定接口抓包，支持使用 `loopback` 选择回环接口。
- 支持设置捕获数量和等待时间，并可使用 Ctrl+C 停止。
- 输出数据包序号、时间、长度和协议摘要，结束时显示收到的包数。

## 后台任务与界面响应

- 抓包、文件读写和分析任务在后台执行，表格批量刷新，减少逐包更新对界面的影响。
- 对待处理队列、保留数据、TCP 会话及载荷设置容量预算，限制数据积累。
- 域名分析和 TCP 流分析支持取消；清空、开始新捕获或成功导入新数据后使旧分析结果失效，避免不同数据集的结果混用。
