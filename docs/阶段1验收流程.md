# 阶段 1 验收流程

本阶段验收命令行选网卡、真实抓包和停止行为。阶段 0 已审核通过；阶段 1 已完成开发验证，等待用户验收。暂不包含 GUI、保存文件或协议筛选，不需要安装 Wireshark。

## 打开项目

打开 PowerShell。在当前开发机器上执行：

```powershell
Set-Location 'D:/研一课程/软件与系统安全/sniffer_1a_git'
```

其他机器请改为实际项目路径，并先按 README 准备环境。本机 `.venv` 与 Npcap 已准备好，无需重复安装或激活虚拟环境。下文命令均在项目目录运行；第二个 PowerShell 只执行 `ping`，无需进入项目目录。

## 查看网卡和交互选择

```powershell
.\.venv\Scripts\python.exe -X utf8 .\sniffer_cli.py --list
```

应显示网卡序号、名称、描述、IPv4、标记和设备标识。“默认建议”是 Scapy 当前建议的接口，“回环”用于本机内部通信。序号只对应本次列表，不应长期记住固定数字。

再运行不带参数的命令：

```powershell
.\.venv\Scripts\python.exe -X utf8 .\sniffer_cli.py
```

- 在选择提示处直接按回车，使用“默认建议”网卡；也可输入本次列表中的序号或精确名称。
- 看到“抓包已就绪”后，可访问网页产生普通网络流量；默认达到 20 包或 30 秒就结束，也可按 `Ctrl+C`。
- 再运行一次相同命令，在选择提示处输入 `q` 并回车，应显示“已取消抓包”，不开始捕获。

如果没有“默认建议”标记，请输入一个有效序号。接口名称含空格时，使用 `--iface` 需用引号包裹；无人交互的脚本运行必须明确提供 `--iface`。

## 验证本机真实流量

使用回环别名，避免猜测 Wi-Fi 或其他网卡：

```powershell
.\.venv\Scripts\python.exe -X utf8 .\sniffer_cli.py --iface loopback --count 0 --timeout 20
```

`--count 0` 不限制包数，`--timeout 20` 为产生流量留出 20 秒。看到“抓包已就绪”后，立即在**第二个 PowerShell 窗口**运行：

```powershell
ping 127.0.0.1
```

回到第一个窗口，检查是否出现包含 `ICMP`、`echo-request`、`echo-reply` 的摘要。每行应有 `#序号`、时间、字节数和摘要；约 20 秒后应返回命令提示符并显示最终包数。必须在抓包期间执行 `ping`，抓包结束后产生的流量不会被记录。

`127.0.0.1` 是本机回环地址，这项测试应选择 `loopback`。回环接口可能混有其他本机程序的流量并产生大量输出；当前阶段不支持筛选，因此总包数不要求等于 `ping` 次数。若未赶上抓包时间，可重新运行这两条命令。

## 验证数量和超时停止

数量停止：在第一个窗口运行以下命令，看到就绪后，在第二个窗口执行 `ping 127.0.0.1`：

```powershell
.\.venv\Scripts\python.exe -X utf8 .\sniffer_cli.py --iface loopback --count 4 --timeout 20
```

收到 4 包后应自动结束，最终统计为 4 包。其他本机流量也计入数量，可能在执行 `ping` 前就达到上限。若 20 秒内不足 4 包，则会按超时结束；需产生流量后重试数量检查。

超时停止：

```powershell
.\.venv\Scripts\python.exe -X utf8 .\sniffer_cli.py --iface loopback --count 0 --timeout 2
```

本次无需主动产生流量。程序应在约 2 秒的捕获等待后结束，接口初始化可能另需少量时间。即使没有收到包也应结束；收到背景流量同样正常，不要求统计为 0。

## 验证 Ctrl+C

先测试有限模式：

```powershell
.\.venv\Scripts\python.exe -X utf8 .\sniffer_cli.py --iface loopback --count 100000 --timeout 120
```

看到就绪后，在抓包窗口按 `Ctrl+C`，应提前结束并显示最终包数，没有 Traceback。再测试数量和时间都无限的模式：

```powershell
.\.venv\Scripts\python.exe -X utf8 .\sniffer_cli.py --iface loopback --count 0 --timeout 0
```

看到就绪后按 `Ctrl+C`，同样应正常结束，无需等待新包。每次结束后可执行 `$LASTEXITCODE`，正常停止应为 `0`。

## 验证错误提示

逐条执行以下命令：

```powershell
.\.venv\Scripts\python.exe -X utf8 .\sniffer_cli.py --iface '__不存在的网卡__'
.\.venv\Scripts\python.exe -X utf8 .\sniffer_cli.py --iface loopback --count -1
.\.venv\Scripts\python.exe -X utf8 .\sniffer_cli.py --iface loopback --timeout -1
```

应分别提示未找到网卡、数量不能小于 0、超时必须为非负有限数，不应开始抓包或出现 Traceback。非法网卡退出码为 `1`，非法参数退出码为 `2`，均属于预期结果。

检查网卡列表、交互选择与取消、回环真实流量、数量停止、超时停止、两种模式的 `Ctrl+C` 和错误提示是否符合上述预期。无需提交抓包日志或临时脚本。
