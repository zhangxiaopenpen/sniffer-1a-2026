# 阶段 4 验收流程：域名证据、DNS 关联与进阶基础 DNS 统计

本文用于在 Windows 本机审核阶段 4。程序只从当前抓到或导入的原始数据包中提取证据和统计，不访问外部 DNS，不做反向解析，不解密 HTTPS，也不跨 TCP 包拼接 HTTP、TLS 或 DNS。统计来自完整稳定分析结果，不随表格筛选改变，也不写入 PCAP。

## 一、启动

在 PowerShell 中进入新仓库并启动 GUI：

```powershell
Set-Location 'D:\研一课程\软件与系统安全\sniffer_1a_git'
.\.venv\Scripts\python.exe -X utf8 .\main.py
```

点击“开始抓包”，访问一个普通网页（例如百度或课程指定网页），等待几秒后点击“停止”。等待状态显示“已停止”且“待处理 0”。阶段 4的分析按钮只能在稳定数据集上使用。

## 二、离线合成验证（推荐先做）

先运行阶段 4 专用域名分析和 GUI 测试：

```powershell
.\.venv\Scripts\python.exe -X utf8 -m unittest discover -s tests -p 'test_domain_analysis.py' -v
.\.venv\Scripts\python.exe -X utf8 -m unittest discover -s tests -p 'test_gui_stage4.py' -v
```

测试覆盖 DNS 查询/应答事务 ID、端点、QNAME、QTYPE、HTTP Host、候选证据、五项 DNS 统计、候选排除、筛选前后统计不变、取消和域名筛选，以及清空/新捕获/导入后的统计失效。当前测试只使用内存合成包，不产生网络流量；统计专用测试共 24 项通过，全量回归 124/124 通过。

## 三、GUI 分析与查看

1. 在停止后的窗口点击“分析域名”。状态会变为“正在分析域名”，窗口仍可操作。
2. 分析完成后，数据包表格会在原八列后出现“域名”和“依据”，并显示“DNS统计”标签。原始编号不因筛选改变。
3. 选中 DNS 查询或响应行，详情下方会显示域名、证据来源、事务 ID、QNAME/QTYPE、A/AAAA/CNAME、TTL 和关联包号。
4. 选中 HTTP 请求行时，“依据”显示“HTTP Host”；同一 TCP 包内的 TLS ClientHello显示“TLS SNI”。
5. 如果显示“DNS/IP/TTL 候选”，这只表示响应地址在 TTL 时间内与包端点相同，不能证明共享 IP 就属于该网站；默认域名筛选排除候选证据。
6. 核对“DNS统计”标签包含五项：查询、响应、匹配事务、未匹配查询、唯一直接域名。唯一直接域名只统计直接证据，DNS/IP/TTL 候选不计入。

## 四、域名筛选

在“域名”输入框输入例如 `www.baidu.com`，先记录筛选前“DNS统计”标签的完整文本，再点击“应用筛选”。它会与协议、IP/CIDR、端口条件按 AND 组合，只改变表格显示，不删除原始包；筛选后五项统计文本必须与筛选前完全一致，保存仍写出全部包。勾选“含候选”后可把 DNS/IP/TTL 候选也纳入筛选；清空条件后点击“重置筛选”，统计仍应保持不变。

## 五、经典 PCAP 验证

点击“打开 pcap”，选择阶段 3 已验证的经典 PCAP 文件。读取完成后进入文件模式，再点击“分析域名”。导入成功会使上一份域名结果和统计失效，并显示“DNS统计：尚未分析”；清空或开始新的实时捕获也必须清除统计。取消分析或导入失败不会发布半成品结果，统计同样保持“尚未分析”。

## 六、保存与边界

- 点击“保存 pcap”时保存的是全部原始包，域名列和依据列属于界面分析结果，不会写入 PCAP。
- PCAPNG、DoH/DoT/DoQ、HTTPS 解密、跨 TCP 分段 HTTP/TLS/DNS 以及外部域名查询均不在阶段 4范围内；不调用 `socket`、`getaddrinfo` 或 `Resolve-DnsName`。
- 畸形、跨包、超过分析包数或原始字节预算的报文不计入可解析统计；候选证据不计入“唯一直接域名”。
- 看到“未找到可用域名证据”只表示当前包内没有可回溯的直接证据，不表示该包一定与网站无关。

## 七、回归检查

验收顺序固定为：先运行两项阶段 4 专用测试，再运行全量回归：

```powershell
.\.venv\Scripts\python.exe -X utf8 -m unittest discover -s tests -p 'test_domain_analysis.py' -v
.\.venv\Scripts\python.exe -X utf8 -m unittest discover -s tests -p 'test_gui_stage4.py' -v
.\.venv\Scripts\python.exe -X utf8 -m unittest discover -s tests -v
```

审核时记录：专用测试结果和全量测试总数（统计专用测试 24 项、全量 124/124）、是否完成离线 PCAP、是否完成 Npcap 实时抓包、五项 DNS 统计标签是否可见、筛选前后统计是否不变、是否查看到 DNS 查询/应答详情、清空/取消/新捕获/导入是否使统计失效，以及保存文件回读后的原始包数量。
